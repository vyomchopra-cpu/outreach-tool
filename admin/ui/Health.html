♥ System

◎ Senders

Cap usage is today's prospect sends against the ramped daily cap. "Reply detection off" means that agent cannot see replies, bounces, or opt-outs — keep those campaigns single-touch.

⇢ Campaign funnel

Sent → replied → opted out, per campaign, plus what is still queued and when the next message is due.

⚠ Recent failures

The first place to look when something is wrong. Empty is good.

🔔 Monitoring & alerts

Runs automatically every 15 minutes — kill switch state, stale agents, a growing backlog of overdue sends, bounce-rate breaches, and unremoved risky addresses. Without a Chat webhook, incidents are still recorded here — you just have to come and look.

🧪 Self-test

Probes the running system rather than the code — the Sheet, the gateway, every sender, real rendering. This is where the failures that reach people actually live: every one so far shipped with a fully green code test suite, because none of them were visible in the source. Run it is read-only and always safe. Run and repair additionally applies fixes that can only ever narrow what the system does — cancelling a send that must not go, closing a dead request, recreating a missing tab. Nothing it does can grant access, extend anyone's window, or send anything.
