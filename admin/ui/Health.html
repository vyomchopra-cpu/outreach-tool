♥ System

◎ Senders

Cap usage is today's prospect sends against the ramped daily cap. "Reply detection off" means that agent cannot see replies, bounces, or opt-outs — keep those campaigns single-touch.

⇢ Campaign funnel

Sent → replied → opted out, per campaign, plus what is still queued and when the next message is due.

⚠ Recent failures

The first place to look when something is wrong. Empty is good.

🔔 Monitoring & alerts

Runs automatically every 15 minutes — kill switch state, stale agents, a growing backlog of overdue sends, bounce-rate breaches, and unremoved risky addresses. Alerts go to Google Chat if configured (Script Properties → CHAT_WEBHOOK_URL) — see admin/Monitor.gs's header comment for one-time setup. Without it, incidents still get recorded here, just no push.

§ Audit trail

Append-only. Every send, admin action, config change, and halt — who, what, when. Never message content.
