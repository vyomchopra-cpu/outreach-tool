Keeping track of replies

Replies come to your inbox as ordinary mail. These optional Gmail filters group them under labels so they are easy to find — and easy to leave alone. Nothing but you can read them.

In Gmail: Settings (gear) → See all settings → Filters and Blocked Addresses → Create a new filter. Paste the line below into the matching field, click Create filter, then tick the actions. Gmail offers to create each label the first time.

Filters never apply to your Sent folder, so messages sent under your name still appear there as normal — they genuinely are your mail.
